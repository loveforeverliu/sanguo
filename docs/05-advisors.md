# 模块 05 · 谋士与策略 — 设计文档

> 状态：⬜ 未做（City 已预留 advisor_id / policy 字段）
> 定位：谋士驻扎加成 + 城市发展策略。

## 一、定位与目标
谋士驻扎城池提供加成；驻扎后可制定城市发展策略。

## 二、谋士类型（5 种）
| 类型 | 加成 |
|------|------|
| 种田 | 粮+20%、人口增长+15% |
| 军事 | 征兵消耗-20%、士兵驻扎-15% |
| 商业 | 铜钱+25%、贸易+10% |
| 科研 | 科技速度+20%、效果+10% |
| 治理 | 人口上限+10%、民心+15% |

## 三、城市策略（City.policy）
| 策略 | 效果 |
|------|------|
| 高税收 | 铜钱+30%、人口增长-20% |
| 低税收 | 铜钱-20%、人口增长+30% |
| 重农 | 粮+20%、铜钱-10% |
| 重商 | 铜钱+20%、粮-10% |
| 休养生息 | 人口增长+50%、产出-20% |

## 四、数据结构
- `data/advisors.json`（待建）：谋士列表 {id, name, type, bonus}
- City 字段：`advisor_id`、`policy`

## 五、接口（建议）
- `City.advisor_bonus()` / `policy_mult()`，乘进 grain_output / coin_output / recruit_unit_cost / grow_population（接 02 公式）

## 六、UI
