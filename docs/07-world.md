# 模块 07 · 世界与扩张 — 设计文档

> 状态：⬜ 未做（当前单城）
> 定位：多城池、势力、AI 对手、占城/驻军/掠夺。

## 一、定位与目标
多城池世界：势力割据、AI 对手、玩家扩张。为 09（玩家与势力）提供势力/城池/敌对势力。

## 二、势力与城池数据
- `data/factions.json`：{id, name, ruler, color, cities[]}
- `data/cities.json`：{id, name, faction_id, tier, 初始建筑/人口/特性}
- 城池等级 tier（接 09，阶梯待细化）

## 三、占城策略
| 策略 | 说明 |
|------|------|
| 开发 | 升级官府/农田，长期收益高，前期投入大 |
| 掠夺 | 一次性大量资源，城池等级下降，长期收益低 |

## 四、驻军系统
- 每城有驻军上限；兵力消耗按「驻军」算，不按「总人口」
- 驻少兵=低耗低防，驻多兵=高耗高防

## 五、扩张逻辑
- 产出增长 > 消耗增长，扩张才有意义
- 官府有规模效应

## 六、AI 对手
- 各势力回合结算；敌对势力可攻打（接 09 战功）

## 七、接口建议
- `Game.cities` 已支持多城（Array），`end_turn` 需扩展 AI 势力结算
- 地图可用纯数据驱动（城池列表 + 邻接关系）
