# 模块 09 · 玩家与势力 — 设计文档

> 状态：🟡 设计阶段（大纲已定，数值留白待细化）。
> 定位：承载「玩家身份 + 势力归属 + 影响力 + 自立 + 大统一」进度系统，以及「概况」总览面板。依赖模块 07（世界与扩张）提供势力/城池/敌对势力。

## 一、设计背景与目标
- 玩家在三国乱世中从「势力部下」起步，最终目标是「**大统一**」。
- 两条成长路线：**辅佐**所在势力统一，或**自立门户**后统一。
- 玩家模块提供：开局选势力、身份定位、影响力进度、概况总览。

## 二、开局流程
1. 开局画面选择势力（魏 / 蜀 / 吴 / 群雄）。
2. 加入该势力，成为其**部下**（一方太守/武将），**不是领袖**。
3. 系统把该势力属地内**最低级城池**分配给玩家作为**治所**（初始唯一城）。
4. 进入游戏；该势力其余城池 + 其它势力城池归 AI/敌方。

## 三、玩家身份与势力
- 势力君主是 **NPC**（不可控），玩家在其麾下效力。
- 城池等级沿用设计文档既有概念：
  - 最低级城市 = 500 人上限（《人口系统》2.1）
  - 人口上限由「房屋 + 城池/官府等级」决定
  - 掠夺会导致城池等级下降（《城市扩张》7.1）
- 完整城池等级阶梯（几级、每级数值）待细化。

## 五、影响力系统
影响力 = 声望 + 战功 + 贡献（是否加权待细化）

| 子项 | 来源 | 获取方式 |
|------|------|----------|
| 声望 | 剿灭黄巾山贼 | 击败黄巾军/山贼营寨 |
| 战功 | 攻打敌对势力 | 按杀敌数量 |
| 贡献 | 向所在势力国库捐献 | 捐铜钱 / 粮草 |

配套内容：
- 黄巾敌人来源：现有「山贼营寨/山寨」归为黄巾，或另建黄巾势力（待定）
- 势力国库 + 捐献操作
- 敌对势力可攻打（选魏 → 蜀/吴/群雄为敌）

## 六、自立系统
- 开局不能自立。
- 影响力达标后解锁「自立」（阈值待细化）。

## 七、胜利条件：大统一
- 路线 A：辅佐所在势力完成大统一。
- 路线 B：自立门户后完成大统一。
- 大统一判定（待定）：占全图 或 灭所有势力。

## 八、概况面板（玩家模块 UI）
- 顶部：君主名 + 势力 + 官爵/称号 + 年份
- 国力：影响力（声望/战功/贡献）+ 国力评分
- 领土：城池数 / 总人口 / 总兵力（分兵种）
- 资源：总铜钱 / 总粮草 / 净收益
- 武将：总数 / 名将数
- 统计：战斗 / 胜利 / 杀敌 / 占城 / 招募

## 九、数据结构（建议字段）
**Player**（`class_name Player extends RefCounted`）
- `name` 君主名、`faction_id` 所属势力、`title` 官爵/称号
- `prestige` 声望、`merit` 战功、`contribution` 贡献
- `influence` 影响力（= 三者合计，派生）
- `stats{}` 累计统计（战斗/胜利/杀敌/占城/招募）
- `to_dict()` / `from_dict()`（存档用，接模块 08）

**Faction**（`data/factions.json`）
- `id`、`name`、`ruler`（NPC 君主）、`color`、`cities[]`（属地）

**City 新增字段**（`data/cities.json`）
- `faction_id`（归属）、`tier`（城池等级，阶梯待定）
